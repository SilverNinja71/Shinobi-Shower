# Shower games

Browser games, each in its own folder. Each one has its own README with how to build and play it.

- `dropout`: Dropout, a shower evasion simulator.
- `shinobi-shower`: Shinobi Shower: The Dry Blade, the 3D version.
- `shinobi-shower-2d`: Shinobi Shower in 2D, a side-scrolling climb.
- `shinobi-shower-1d`: Shinobi Shower 1D, a one-lane raindrop slicer with levels 1–50.
- `shinobi-bridge-1d`: Shinobi Shower 1D: The Precarious Peak, the same one lane rebuilt in Three.js as a swaying rope bridge between storm-lashed peaks.
